# Student-Management-System
This project is a console-based student management system written in C/C++ style using a linked list data structure. It allows the user to add student records, delete a student by ID, calculate the average grade of each student, sort students based on their average score, and save each student’s information into a separate text file automatically. The program also provides an option to search and display a student’s full information by ID. Each student record includes the student’s name, ID, programming grade, English grade, math grade, and final average. This project demonstrates the use of linked lists, file handling, sorting, and basic menu-driven program design.
